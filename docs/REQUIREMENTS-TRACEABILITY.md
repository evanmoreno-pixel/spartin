# SpartIN requirements traceability

Phase 4 uses the requirement identifiers from [PRD §5](PRD.md) and the design and validation references in [SAD](SAD.md), [SFDS](SFDS.md), and [TP](TP.md). The wording below summarizes the requirements. Historical test references are preserved. The Phase 4 evidence identifiers point to tests executed against the current code.

## Test Plan cross-reference

TP §6.1 gives full example rows for TC-001–004. TC-001 expects real SJSU authentication and remains **Simulated** for this release. TC-002 describes CSV export and remains **Deferred**. TC-003 and TC-004 map to the waitlist and CRUD evidence above. The separate TP security cross-reference to TC-002 is inconsistent with the CSV example and carries no security pass.

TP §6.2 references additional IDs without complete procedures. These are coverage pointers, not separately executed historical cases.
